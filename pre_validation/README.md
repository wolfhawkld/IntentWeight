# Phase 1A: 意图聚类方法验证

**目标**: 验证意图聚类方法的有效性，确定技术方案

## 数据集

| 数据集 | 规模 | 意图数 | 领域 |
|-------|------|-------|------|
| BANKING77 | 13K | 77 | 银行 |
| CLINC150 | 23K | 150 | 多领域 |

## 任务清单

### Week 1: 数据准备与基线建立

- [ ] 下载数据集 (BANKING77, CLINC150)
- [ ] 数据预处理与清洗
- [ ] 基线模型: K-Means + BERT
- [ ] 基线评估指标记录

### Week 2: 意图聚类实现

- [ ] Embedding生成 (SBERT/SimCSE)
- [ ] HDBSCAN聚类实现
- [ ] 聚类参数调优
- [ ] 聚类质量评估 (轮廓系数, NMI, ARI)

### Week 3: 实体增强实验

- [ ] 实体识别 (NER)
- [ ] 实体特征融合
- [ ] 消融实验: 有/无实体增强对比
- [ ] 效果分析报告

## 评估指标

| 指标 | 目标 | 说明 |
|-----|------|------|
| 轮廓系数 | > 0.5 | 聚类紧密度 |
| NMI | > 0.7 | 与真实标签一致性 |
| ARI | > 0.6 | 聚类准确度 |

## 产出

- [ ] 意图聚类代码
- [ ] 实验数据与分析报告
- [ ] 技术方案确定
