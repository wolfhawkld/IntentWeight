## 论文1: 意图驱动的知识检索系统

### 标题

**Intent-Driven Knowledge Retrieval: Hierarchical Recognition and Weighted Matching**

### 核心贡献

1. **多层意图识别框架**
   - 第一层: Speech Act 过滤（过滤无关/需澄清意图）
   - 第二层: 问题复杂度分析（决定检索策略）
   - 第三层: 领域意图识别（细分任务类型）
   - 输出: 多维意图向量

2. **意图向量表示与融合**
   - 各层意图的向量编码方法
   - 多层意图融合公式
   - 意图向量归一化

3. **意图权重化RAG**
   - 数据对象携带意图权重
   - 意图对齐匹配公式
   - 权重初始化与更新策略

4. **端到端检索流程**
   ```
   问题 → 多层意图识别 → 意图向量 → 数据意图权重匹配 → 精准召回 → 答案生成
   ```

### 创新点

| 创新点 | 说明 | 验证状态 |
|-------|------|---------|
| Speech Act 作为过滤层 | 有效过滤无关意图 | ✅ 已验证 (90%准确率) |
| 数据级意图权重 | 同一数据不同意图下权重不同 | ⏳ 待验证 |
| 意图对齐匹配 | 问题意图 ∩ 数据意图 | ⏳ 待验证 |

### 实验设计

1. **意图识别实验**
   - 各层分类准确率
   - 与传统单层意图分类对比
   - 不同清晰度问题的表现

2. **检索效果实验**
   - 召回准确率 vs 传统RAG
   - 不同意图分布下的表现
   - 筛选效率对比

3. **消融实验**
   - 去掉某一层的影响
   - 不同意图权重初始化方法对比

### 数据集

- NLPCC-KBQA (中文)
- KgCLUE (中文)
- BANKING77 / CLINC150 (对比实验)

### 投稿方向

- **首选**: ACL / EMNLP (NLP顶会)
- **备选**: SIGIR / WWW (IR顶会)

## 论文2: 可自我进化的知识智能体

### 标题

**Self-Evolving Knowledge Agent: Reinforcement Learning from User Feedback**

### 核心贡献

1. **意图驱动的ReAct框架**
   - 意图向量指导任务拆解
   - 意图感知的策略选择
   - 上下文意图追踪

2. **多类型RAG统一调度**
   - 向量库 / 图谱 / 文档库 / 结构化数据
   - 基于意图向量的策略路由
   - 检索策略与意图解耦

3. **用户反馈收集机制**
   - 显式反馈: 评分、点赞、纠错
   - 隐式反馈: 点击、停留时间、追问
   - 反馈信号融合方法

4. **RL优化意图权重**
   - 状态: 意图向量 + 召回数据
   - 动作: 调整意图权重
   - 奖励: 用户反馈信号
   - 优化目标: 最大化长期满意度

5. **防护机制**
   - 投毒检测: 异常反馈过滤
   - 局部最优避免: ε-greedy探索 + 多样性奖励

### 创新点

| 创新点 | 说明 | 验证状态 |
|-------|------|---------|
| 意图感知任务拆解 | 意图向量指导ReAct规划 | ⏳ 待验证 |
| 反馈驱动优化 | RL持续学习意图权重 | ⏳ 待验证 |
| 安全体制 | 投毒检测+局部最优防护 | ⏳ 待验证 |

### 实验设计

1. **任务拆解实验**
   - 多跳问答准确率
   - 任务拆解合理性评估
   - 与传统ReAct对比

2. **自我进化实验**
   - 长期交互优化效果
   - 用户满意度演化曲线
   - 权重收敛分析

3. **安全实验**
   - 模拟投毒攻击
   - 防护机制有效性
   - 探索策略效果

### 实验平台

- 企业内部知识库场景
- 模拟用户交互环境
- A/B测试框架

### 投稿方向

- **首选**: AAAI / NAACL (AI/NLP顶会)
- **备选**: TOIS / TIST (系统期刊)
