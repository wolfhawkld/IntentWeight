# 中文知识库问答 QA 示例

**创建时间**: 2026-03-29
**目的**: 展示问题语义清晰度差异，支持 IntentWeight 项目研究

---

## 一、问题语义清晰度分类

### 1.1 清晰明了的专业问题 (Precise Questions)

**特征**：
- 明确的实体 + 明确的属性/关系
- 无歧义、无省略、无模糊表达
- 可直接映射到 KG 三元组

| 问题示例 | 实体 | 关系/属性 | 清晰度 |
|---------|------|----------|--------|
| 姚明的身高是多少？ | 姚明 | 身高 | ⭐⭐⭐⭐⭐ |
| 《三体》的作者是谁？ | 三体(小说) | 作者 | ⭐⭐⭐⭐⭐ |
| 北京大学成立于哪一年？ | 北京大学 | 成立时间 | ⭐⭐⭐⭐⭐ |
| 中国的首都是哪个城市？ | 中国 | 首都 | ⭐⭐⭐⭐⭐ |
| 马云的出生地在哪里？ | 马云 | 出生地 | ⭐⭐⭐⭐⭐ |
| 华为公司的创始人是谁？ | 华为 | 创始人 | ⭐⭐⭐⭐⭐ |
| 相对论是谁提出的？ | 相对论 | 提出者 | ⭐⭐⭐⭐⭐ |
| 2024年奥运会举办城市？ | 2024奥运会 | 举办城市 | ⭐⭐⭐⭐⭐ |

**KG 映射**：
```
(姚明, 身高, 2.26米)
(三体, 作者, 刘慈欣)
(北京大学, 成立时间, 1898年)
```

---

### 1.2 略带模糊但可推断的问题 (Moderately Clear)

**特征**：
- 实体或属性有省略，但可从上下文推断
- 存在常见表达习惯，人类可理解
- 需要一定的知识/常识补全

| 问题示例 | 模糊点 | 推断需求 | 清晰度 |
|---------|--------|---------|--------|
| 姚明多高？ | "多高"→"身高" | 属性词省略 | ⭐⭐⭐⭐ |
| 三体谁写的？ | "谁写的"→"作者" | 谓语转属性 | ⭐⭐⭐⭐ |
| 马云哪里人？ | "哪里人"→"出生地/籍贯" | 口语化表达 | ⭐⭐⭐⭐ |
| 华为谁创办的？ | "谁创办的"→"创始人" | 谓语转属性 | ⭐⭐⭐⭐ |
| 苹果的CEO | 省略"是谁" | 问句不完整 | ⭐⭐⭐ |
| 特斯拉的市值 | 省略"是多少" | 问句不完整 | ⭐⭐⭐ |

**处理策略**：
```
问题: "姚明多高？"
推断: 多高 → 身高属性
映射: (姚明, 身高, ?)
```

---

### 1.3 含糊不清的模糊语义问题 (Vague Questions)

**特征**：
- 实体不明确（多义词、指代不明）
- 意图不清晰（想问什么不明确）
- 需要多轮澄清

#### 类型A：实体歧义

| 问题示例 | 歧义点 | 可能指代 | 清晰度 |
|---------|--------|---------|--------|
| 苹果的CEO是谁？ | "苹果" | 苹果公司 / 水果 / 苹果品牌 | ⭐⭐ |
| 小米的创始人？ | "小米" | 小米公司 / 小米(粮食) | ⭐⭐ |
| 特斯拉的价格？ | "特斯拉" / "价格" | 特斯拉公司股价 / 特斯拉汽车价格 / 哪款车？ | ⭐ |
| 阿里巴巴在哪里？ | "阿里巴巴" | 阿里巴巴公司 / 童话人物 | ⭐⭐ |
| 腾讯的游戏？ | "游戏" | 哪款游戏？还是游戏列表？ | ⭐⭐ |

**澄清示例**：
```
用户: 苹果的CEO是谁？
系统: 您是指苹果公司(Apple Inc.)吗？
用户: 是的
系统: 苹果公司的现任CEO是蒂姆·库克。
```

#### 类型B：意图模糊

| 问题示例 | 模糊点 | 可能意图 | 清晰度 |
|---------|--------|---------|--------|
| 这个怎么弄？ | "这个"指代不明 | 指代消解失败 | ⭐ |
| 有什么要注意的？ | 问题范围太广 | 需要限定领域 | ⭐ |
| 那个文档在哪里？ | "那个"指代不明 | 需要上下文 | ⭐ |
| 能帮我查一下吗？ | 查什么？ | 意图未表达 | ⭐ |
| 这是什么情况？ | 指代不明 | 需要上下文 | ⭐ |

**澄清示例**：
```
用户: 有什么要注意的？
系统: 您想了解哪个方面的注意事项？
      1. 产品使用
      2. 安全规范
      3. 法律合规
用户: 产品使用
系统: 好的，关于产品使用，有以下几点注意事项...
```

#### 类型C：笼统问法

| 问题示例 | 模糊点 | 需要澄清 | 清晰度 |
|---------|--------|---------|--------|
| 告诉我关于华为的信息 | 信息范围太广 | 哪类信息？ | ⭐ |
| 阿里巴巴怎么样？ | "怎么样"含义不明 | 评价？业务？股价？ | ⭐ |
| 这两个有什么区别？ | "两个"指代不明 | 需要上下文 | ⭐ |
| 推荐一款手机 | 需求不明确 | 品牌？价位？用途？ | ⭐⭐ |
| 怎么学编程？ | 问题太笼统 | 语言？方向？ | ⭐⭐ |

**澄清示例**：
```
用户: 告诉我关于华为的信息
系统: 您想了解华为的哪方面信息？
      1. 公司简介
      2. 主要产品
      3. 财务状况
      4. 发展历程
用户: 主要产品
系统: 华为的主要产品包括...
```

### 1.4 企业内部知识库典型问答示例

#### 清晰问题（专业场景）

| 场景 | 问题示例 | 意图类型 |
|-----|---------|---------|
| HR | 公司的年假制度是怎样的？ | T_RULES |
| HR | 请假流程是什么？ | I_PROCEDURE |
| 财务 | 报销需要哪些材料？ | T_RESOURCES |
| 财务 | 差旅费的报销上限是多少？ | I_FACTOID |
| IT | VPN怎么连接？ | I_PROCEDURE |
| IT | 公司WiFi密码是什么？ | I_FACTOID |
| 行政 | 会议室怎么预约？ | I_PROCEDURE |
| 法务 | 合同审批流程是什么？ | I_PROCEDURE |

#### 模糊问题（实际场景）

| 场景 | 问题示例 | 模糊点 | 澄清需求 |
|-----|---------|--------|---------|
| HR | 请假怎么请？ | 请假类型不明 | 年假/病假/事假？ |
| 财务 | 这个能报销吗？ | "这个"指代不明 | 需要明确费用类型 |
| IT | 网络不行怎么办？ | 问题范围太广 | WiFi/VPN/内网？ |
| 行政 | 会议室在哪？ | 哪个会议室？ | 需要具体位置 |
| 法务 | 合同怎么签？ | 签约阶段不明 | 起草/审批/盖章？ |

```json
{
  "question": "姚明的身高是多少？",
  "entity": "姚明",
  "relation": "身高",
  "answer": "2.26米"

```

### 2.3 数据集问题类型分布

| 问题类型 | NLPCC-KBQA | KgCLUE | 说明 |

| 事实型(Factoid) | ~60% | ~55% | "X是多少？" |

## 三、歧义问题分类体系

### 3.1 歧义类型

```
┌─────────────────────────────────────────────────────────────┐
│                    问题歧义分类                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 实体歧义 (Entity Ambiguity)                             │
│     ├─ 多义词: "苹果"→公司/水果/品牌                        │
│     ├─ 缩写: "阿里"→阿里巴巴/阿里地区                       │
│     └─ 人名重名: "王伟"→多人同名                            │
│                                                             │
│  2. 关系歧义 (Relation Ambiguity)                           │
│     ├─ 同义关系: "创始人"/"创办者"/"建立者"                 │
│     ├─ 层级关系: "价格"→原价/现价/股价                      │
│     └─ 多值关系: "兄弟姐妹"→可能有多个                      │
│                                                             │
│  3. 意图歧义 (Intent Ambiguity)                             │
│     ├─ 范围模糊: "关于X的信息"→哪个方面？                   │
│     ├─ 问题不完整: "苹果的CEO"→省略问句                     │
│     └─ 口语化: "X怎么样"→评价/介绍/现状？                   │
│                                                             │
│  4. 上下文歧义 (Context Ambiguity)                          │
│     ├─ 指代不明: "这个"、"那个"、"它"                       │
│     ├─ 省略: "多少钱"→省略主语                              │
│     └─ 多轮依赖: 需要前文信息                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 歧义示例详解

#### 实体歧义示例

```
问题: "苹果的市值是多少？"

歧义分析:
┌─────────────────────────────────────────────┐
│ 候选实体:                                    │
│ 1. 苹果公司 (Apple Inc.) → 科技公司         │
│ 2. 苹果 (水果) → 农产品                      │
│ 3. 苹果 (品牌) → 可能指其他品牌              │
│                                              │
│ KG 查询:                                     │
│ (苹果公司, 市值, 约3万亿美元)                │
│ (苹果, 市值, ?) → 无效查询                   │
│                                              │
│ 澄清策略:                                    │
│ "您是指苹果公司(Apple Inc.)的市值吗？"       │
└─────────────────────────────────────────────┘
```

#### 关系歧义示例

```
问题: "特斯拉的价格？"

歧义分析:
┌─────────────────────────────────────────────┐
│ 可能意图:                                    │
│ 1. 特斯拉公司股价                            │
│ 2. 特斯拉汽车价格                            │
│ 3. 特斯拉某款车型价格                        │
│                                              │
│ 澄清策略:                                    │
│ "您想了解:                                   │
│  1. 特斯拉公司股价                           │
│  2. 特斯拉汽车价格                           │
│ 请选择..."                                   │
└─────────────────────────────────────────────┘
```

## 四、对 IntentWeight 项目的应用价值

### 4.1 问题清晰度评估

| 清晰度 | 意图分类难度 | 处理策略 |
|-------|-------------|---------|
| ⭐⭐⭐⭐⭐ | 低 | 直接回答 |
| ⭐⭐⭐⭐ | 中 | 补全后回答 |
| ⭐⭐⭐ | 高 | 意图推断+确认 |
| ⭐⭐ | 很高 | 多轮澄清 |
| ⭐ | 极高 | 引导式对话 |

### 4.2 意图分类与问题清晰度的关系

```
Speech Act 分类:
├─ 清晰问题 → 高置信度分类 → 直接处理
├─ 模糊问题 → 中置信度分类 → 需要澄清
└─ 笼统问题 → 低置信度分类 → 需要引导

处理流程:
问题输入 → Speech Act分类 → 置信度评估
    ↓
置信度高 → 执行回答
置信度中 → 澄清确认
置信度低 → 引导对话
```

### 4.3 实验建议

**实验设计**：
1. 从 NLPCC-KBQA 抽取清晰问题样本
2. 人工构造模糊/笼统问题变体
3. 测试 Speech Act 分类器在不同清晰度问题上的表现
4. 分析置信度分布与问题清晰度的相关性
