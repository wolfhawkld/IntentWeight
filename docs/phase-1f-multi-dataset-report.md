## 关键洞察

### 洞察1: 低纯度数据集更需要关键词先验

| 数据集 | 纯度 | 先验优势 | 解释 |
|--------|------|----------|------|
| CMID_FINE | 36.16% | +56% | 簇纯度低，向量检索噪声大，先验提供精准过滤 |
| CMID | 66.18% | +38% | 中纯度，向量检索有噪声，先验有效过滤 |
| BANKING77 | 94.87% | +6% | 高纯度，向量本身效果好，先验提供微调优化 |

### 洞察2: 意图覆盖是关键约束

| 数据集 | 意图数 | 意图覆盖 | 先验效果 |
|--------|--------|----------|----------|
| BANKING77 | 77 | 97.4% | ✓ 优秀 |
| CMID | 4 | 100% | ✓ 优秀 |
| CLINC150 | **151** | **88.7%** | ⚠ 受限 |
| CMID_FINE | 40 | **42.5%** | ⚠ 受限 |

**原因**: 意图覆盖不足→部分意图无匹配簇→先验策略无法召回

### 洞察3: 先验差距随纯度降低而增大

```
CMID_FINE: 纯度36.16% → 先验差距0.420 (最大)
CMID:      纯度66.18% → 先验差距0.304
BANKING77: 纯度94.87% → 先验差距0.319
```

**解释**: 低纯度簇的语义混乱度高，关键词先验提供了更强的区分信号

## 实践建议

### 根据数据集特征选择策略

| 数据集特征 | 推荐策略 | 说明 |
|-----------|---------|------|
| 高纯度 + 高意图覆盖 | 先验+向量融合 | 先验略优化，向量保底 |
| 高纯度 + 低意图覆盖 | 向量为主 | 先验可能遗漏意图 |
| 低纯度 + 高意图覆盖 | **先验为主** | 先验优势显著 |
| 低纯度 + 低意图覆盖 | 先验+向量融合 | 先验提升大，向量覆盖遗漏 |

### CLINC150案例分析

```
问题：意图151类，覆盖88.7%，先验-6% vs向量

解决方案：
1. 扩展意图覆盖：补充遗漏意图的簇
2. 双路径召回：先验召回 + 向量召回 → 融合
3. 意图分类优先：先意图分类 → 再簇选择

改进后预期：先验准确率80%+，向量保底覆盖遗漏意图
```
