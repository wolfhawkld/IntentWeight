## 系统概述

一个**可自我进化的知识智能体**，通过多层意图识别、ReAct Agent、多类型 RAG、用户反馈优化，实现与人类交互后持续进化的智能问答系统。

## 五大核心设计

### 1. 多层意图识别

**目标**: 不同层实现不同维度的意图识别，最终转换为确定流程。

| 层级 | 作用 | 输出 | 状态 |
|-----|------|------|------|
| **第一层** | Speech Act 过滤 | 过滤无关/需澄清意图 | ✅ 已验证 |
| **第二层** | 问题复杂度分析 | 简单/多跳/结构化 | ⏳ 待实现 |
| **第三层** | 领域意图识别 | 具体领域/任务 | ⏳ 待实现 |
| **输出** | 意图向量 | 多维意图表示 | ⏳ 待实现 |

**已验证结论**: Speech Act 层可有效过滤无关或需澄清的意图。

---

### 2. ReAct Agent 核心

**目标**: 通过 Loop + 策略机制，实现上下文关联和任务拆解。

```
┌─────────────────────────────────────────┐
│            ReAct Loop                   │
│                                         │
│   Thought → Action → Observation        │
│      ↑                    │             │
│      └────────────────────┘             │
│                                         │
│   能力:                                  │
│   - 上下文关联意图分析                   │
│   - 任务拆解与规划                       │
│   - 多步骤任务执行                       │
│   - 动态策略调整                         │
└─────────────────────────────────────────┘
```

**关键特性**:
- **上下文关联**: 理解多轮对话中的意图演变
- **任务拆解**: 将复杂问题拆解为子任务
- **策略选择**: 根据意图选择合适的执行路径

---

### 3. RAG 数据层意图权重

**目标**: 每个数据对象携带意图权重，通过意图向量匹配实现精准筛选。

```json
{
  "data_object": {
    "id": "doc_001",
    "content": "公司的年假制度规定...",
    "type": "policy_document",
    
    "intent_weights": {
      "leave_policy_inquiry": 0.95,
      "hr_consultation": 0.85,
      "benefits_overview": 0.60,
      "onboarding_guide": 0.30
    }
  }
}
```

**匹配公式**:
```
Score(Data, Question) = Σ( Intent_Vector[i] × Data_Intent_Weight[i] )

其中:
  Intent_Vector = 多层意图识别输出的意图向量
  Data_Intent_Weight = 数据对象的意图权重
```

**优势**:
- 同一数据在不同意图下有不同权重
- 意图对齐 = 问题意图 ∩ 数据意图
- 权重可通过用户反馈优化

### 5. 检索策略与意图分离

**核心原则**: 检索策略仅影响任务子流程的选取，不影响意图识别和意图对齐。

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   意图识别层 (不变)                                         │
│   ─────────────────                                         │
│   输出: 意图向量 [0.8, 0.3, 0.1, ...]                       │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   检索策略层 (可变)                                         │
│   ─────────────────                                         │
│   根据意图向量选择:                                          │
│   - 向量搜索 (简单事实)                                     │
│   - 图谱搜索 (多跳推理)                                     │
│   - 混合搜索 (复杂场景)                                     │
│                                                             │
│   但不影响:                                                  │
│   - 意图识别结果                                           │
│   - 意图对齐匹配                                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**设计优势**:
- 意图识别与检索策略解耦
- 可独立优化各层
- 便于扩展新的检索策略

## 数据流示意

```
用户: "姚明妻子的出生地在哪里？"

    ↓ 第一层: Speech Act
    → ASSERTIVE (询问事实) ✅ 通过

    ↓ 第二层: 问题复杂度
    → 多跳关系 (妻子→出生地)

    ↓ 第三层: 领域意图
    → 人物关系查询

    ↓ 意图向量
    → [assertive: 0.9, multi_hop: 0.8, person_relation: 0.7]

    ↓ ReAct Agent
    → 拆解: (姚明) --妻子--> (?) --出生地--> (?)
    → 策略: 图谱搜索

    ↓ RAG 数据层
    → 图谱查询执行
    → 意图权重匹配
    → 数据: (姚明, 妻子, 叶莉), (叶莉, 出生地, 上海)

    ↓ 答案生成
    → "姚明的妻子叶莉出生在上海。"

    ↓ 用户反馈
    → 点赞 ✅
    → 更新相关数据的意图权重
```

## 关键设计决策

### 意图对齐公式

```
Alignment(Question, Data) = cosine_similarity(
    Intent_Vector(Question),
    Intent_Weight_Vector(Data)
)
```

### 自我进化目标函数

```
Maximize: Σ γ^t × Reward_t

其中:
  Reward_t = 用户反馈信号
  γ = 折扣因子
  t = 时间步
```

### 投毒检测阈值

```
if |Feedback_Deviation| > Threshold:
    标记为可疑反馈
    降低该反馈对权重更新的影响
```
